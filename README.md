# PERL library required for the LADCP_w processing software

## Notes

- To find out which version is installed, run "make" in the install
directory.

- While there is no official support for this software feel free to
contact the author with questions or requests.

- Most of the source files use a hard tab of 4 spaces, i.e. they can be
viewed correctly, e.g. with "less -x4".
